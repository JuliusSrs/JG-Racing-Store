# JG RACING STORE

A Formula 1-inspired racing toys online store built with HTML, CSS, and JavaScript.

## Features
- Product catalog with categories, search, sorting, and product details
- Shopping cart and demo checkout (cart is saved in the browser)
- Racing mini-game (F1 Click-to-Race Challenge)
- About the Author page
- Light and dark mode toggle
- Racing cursor effect (desktop only)

## Files
- `index.html` – page structure
- `style.css` – design and gradients
- `script.js` – products, cart, game, and interactivity
- `images/` – product photos (see `IMAGE-GUIDE.md`)

## How to run
Open `index.html` in a browser.
